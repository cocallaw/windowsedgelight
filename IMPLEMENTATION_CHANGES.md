## Feature 1: Temperature Slider

### What It Does
- Allows users to adjust light color from warm (2700K) to cool (6500K)
- Real-time visual feedback as slider moves
- Temperature displayed as "XXXXK" next to slider
- Setting persists across application restarts

### User Interface
```
Temperature: 🔥 [===========|========] ❄️ 6500K
            Warm              Cool
```

### How to Use
- Move slider left for warmer light (more orange/yellow)
- Move slider right for cooler light (more blue/white)
- Current temperature shown on right side
- Also accessible via system tray menu

## Feature 2: Three Presets

### What It Does
- Save three custom combinations of temperature + brightness
- Quick recall of favorite settings
- Each preset independent and customizable
- All presets persist across restarts

### User Interface
```
Presets: [  1  ] [  2  ] [  3  ]
```

### How to Use
- **Load Preset**: Click button (1, 2, or 3)
- **Save Preset**: Hold Ctrl + Click button
- Confirmation message shows when preset is saved
- Also accessible via system tray menu

### Default Presets
| Preset | Temperature | Brightness | Description |
|--------|-------------|------------|-------------|
| 1      | 6500K       | 100%       | Cool white, full brightness |
| 2      | 4500K       | 70%        | Neutral, moderate brightness |
| 3      | 2700K       | 50%        | Warm white, dim |

## Temperature Algorithm

The color temperature conversion uses industry-standard formulas:

```csharp
// For temperatures 2700K - 6500K
// Converts Kelvin to RGB (0-255)
private Color TemperatureToColor(int temperature)
{
    double temp = temperature / 100.0;
    
    // Red calculation
    if (temp <= 66) red = 255;
    else red = 329.698727446 * Math.Pow(temp - 60, -0.1332047592);
    
    // Green calculation
    if (temp <= 66) green = 99.4708025861 * Math.Log(temp) - 161.1195681661;
    else green = 288.1221695283 * Math.Pow(temp - 60, -0.0755148492);
    
    // Blue calculation
    if (temp >= 66) blue = 255;
    else if (temp <= 19) blue = 0;
    else blue = 138.5177312231 * Math.Log(temp - 10) - 305.0447927307;
    
    return Color.FromRgb((byte)red, (byte)green, (byte)blue);
}
```
